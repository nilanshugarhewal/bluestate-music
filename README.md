## About The Project

**BlueState Music** is a self-hosted music platform built to showcase and stream original type beats and productions. Built with a modern TypeScript + React stack, it delivers a clean, fast, and distraction-free listening experience, fully owned and controlled by the artist, with no third-party platform limitations.

This project was created as a personal home for my music. A space where I can upload, organize, and share my type beats and productions directly with listeners.

> 🔗 **Live site:** [bluestate.vercel.app](https://bluestate.vercel.app)

---

## ✨ Features

- 🎧 **Browse & Discover** — Explore tracks in a clean, organized layout
- ▶️ **Full Playback Controls** — Play, pause, seek, and manage audio effortlessly
- 📱 **Responsive Design** — Works smoothly across desktop, tablet, and mobile
- ⚡ **Fast & Reliable** — Deployed on Vercel's edge network for low-latency delivery
- 🗄️ **Cloud Database** — Track data and metadata managed via MongoDB Atlas
